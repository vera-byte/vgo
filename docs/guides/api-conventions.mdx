## 响应封装

所有业务接口统一返回三字段结构（`v.MiddlewareHandlerResponse`）：

```json
{ "code": 1000, "message": "BaseResMessage", "data": { … } }
```

| code | 含义 |
|------|------|
| 1000 | 成功 |
| 1001 | 业务失败 / 登录失效 / 无权限（message 区分） |
| 403 | 无权限（HTTP 403，`登录失效或无权限访问~`） |
| 401 | 未登录（HTTP 401，`登陆失效～`） |
| 429 | 触发限流（`请求过于频繁，请稍后再试`） |
| 4001–4008 | 开放平台签名相关（见下） |

前端判定成功仅需 `code == 1000`。

## 错误脱敏

服务端对外错误遵循以下策略：

- **业务错误**（`gerror.New("中文提示")`）：原文返回给客户端
- **内部错误**（SQL/网络异常、超长报文、含 `pq:`/`SQLSTATE`/换行的报文）：统一返回
  `系统繁忙，请稍后再试`，完整错误仅记录到服务端日志

控制器中请直接 `return nil, err` 交由统一中间件处理，**不要**自行 `Fail(err.Error())` 透传内部错误。

## 日志脱敏

- 验证码明文严禁进入日志（仅记录 captchaId）
- 请求参数日志（base_sys_log）注意不要传入明文密码字段（已知问题见 [已知问题](/known-issues)）

## 请求规范

| 项目 | 约定 |
|------|------|
| 认证头 | `Authorization: <token>`（兼容 `Bearer ` 前缀） |
| 时间格式 | `Y-m-d H:i:s` 字符串或 `time.Time` JSON |
| 分页参数 | `page`（从 1 起）、`size` |
| 关键字 | `keyWord`（匹配 QueryOp.KeyWordField） |
| 排序 | `order`（字段，支持 `a.b` 形式）+ `sort`（asc/desc），非法值直接拒绝 |
| 删除 | `{"ids": [1,2,3]}` |
| 上传 | `multipart/form-data`，字段名 `file`；扩展名白名单见下 |

## 上传白名单

允许：`.jpg .jpeg .png .gif .webp .bmp`、`.pdf .txt .md .csv`、`.doc(x) .xls(x) .ppt(x)`、`.zip .rar .7z`、`.mp3 .mp4 .wav .avi .mov`

拒绝：其余全部（含 `.html .svg .js .php .exe` 等）。存储文件名随机生成（`随机串.扩展名`），原文件名不参与落盘。

## 开放平台错误码

| code | 含义 |
|------|------|
| 4001 | 缺少应用 ID（X-App-Id） |
| 4002 | 缺少时间戳 |
| 4003 | 缺少随机数 |
| 4004 | 缺少签名 |
| 4005 | 时间戳超出 5 分钟窗口 |
| 4006 | 应用不存在或已禁用 |
| 4007 | 请勿重复请求（nonce 重放） |
| 4008 | 签名验证出错（内部异常） |
| 4009 | 签名验证不通过（签名错误） |
