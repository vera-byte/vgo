所有密钥与环境相关配置通过环境变量注入，配置文件中以 `${VAR}` 占位符引用。

## 业务配置

| 变量 | 必填 | 说明 | 示例 |
|------|------|------|------|
| `VGO_DB_PASS` | 是 | 业务数据库密码 | `your_db_password` |
| `VGO_REDIS_PASS` | 视配置 | Redis 密码（无密码留空） | `your_redis_password` |
| `VGO_OSS_ACCESS_KEY_ID` | 用 minio/oss 时 | 对象存储 AccessKey | — |
| `VGO_OSS_SECRET_ACCESS_KEY` | 用 minio/oss 时 | 对象存储 SecretKey | — |

## docker-compose 本地开发

| 变量 | 说明 |
|------|------|
| `POSTGRES_PASSWORD` | Postgres 初始化密码（应与 `VGO_DB_PASS` 一致） |
| `MYSQL_ROOT_PASSWORD` | MySQL root 密码 |
| `MYSQL_PASSWORD` | MySQL 业务库密码 |

## 展开规则

- 应用启动时自动加载工作目录 `.env`（已显式设置的环境变量优先，不会被覆盖）
- 仅支持 `${VAR}` 形式（`$VAR` 不展开）
- 未设置的变量展开为空字符串
- 展开发生在进程启动阶段（`v/vconfig` 初始化），覆盖：
  - `v.GetCfgWithDefault` 业务配置读取
  - `g.Cfg()` 全局配置（`database.*` / `redis.*`）

## 运行环境要求

| 项 | 版本 |
|----|------|
| Go | 1.27.3+ |
| PostgreSQL | 15+ |
| Redis | 7+ |
