## v1.2.4（2026-11）—— init 模板依赖版本热修

- **修复 v1.2.3 init 模板编译失败**：模板 go.mod 误钉 `v1.2.2`（无 `RegisterMigrationFS`），生成项目缺符号；改为钉 **v1.2.3 最低要求集**（MVS 下限、可被依赖抬升，不随发版漂移）

## v1.2.3（2026-11）—— 迁移注册表与模块脚手架派生

- **迁移注册表**：各模块根文件 `//go:embed resource/migrates` 内嵌迁移并 `v.RegisterMigrationFS` 注册；migrate 命令双源（本地目录 ∪ 内嵌 FS）按模块名排序执行——修复生成项目 migrate 只能看到本地模块、框架 9 模块迁移无法执行的问题（demo 触发器次序一并修复）
- **`vgo-tools module` 派生改写**：表名/类型/路由/文件名/包名随模块名生成（`demotest_sample`/`DemotestSample`/`/admin/demotest/`），修复复制模块与 demo 撞表撞路由；内嵌迁移注册名同步防多模块覆盖

## v1.2.2（2026-11）—— 命令体系共享与 init 模板对齐

- **命令体系迁移 `v/vcmd` 公开包（破坏性）**：`internal/cmd`（registry/server/migrate/pack）迁至 `github.com/vera-byte/vgo/v/vcmd`——生成项目与 vgo 主仓共享同一套命令树（`server`/`migrate`/`pack`/`utils` + 各模块 CommandProvider 命令），根因是 Go internal 规则禁止生成项目 import 原包，模块命令此前在 init 项目里无人消费、migrate 缺失、`v.NewVgo()` 从不执行
- **init 模板对齐现行入口**：main.go/internal 改为 vcmd 形态 + `internal/loader`；删除模板内 2024 年旧 `internal/cmd`；配置/依赖钉 v1.2.2
- **`vgo-tools module` 修复**：模板脚手架 `modules/demo` 缺失致 nil panic（P0）、错误 exit=0（P1）、描述不符（P2）、go.mod 解析误匹配（P3）——脚手架按现行范式补回（model/service/controller/api/migrates），新增包名合法化与 `modules/modules.go` 自动接线

## v1.2.0（2026-11）—— 用户模块与插件工具链

### 新增
- **用户模块（C 端）**：手机验证码登录（自动注册）、密码登录（bcrypt）、微信小程序登录（code2session + 手机号解密）、个人资料、收货地址（归属过滤防 IDOR、默认地址互斥）
  - 会话用 sa-token-go `integrations/gf`（独立 StpLogic，与管理端会话隔离），登录响应 `{expire,token,refreshExpire,refreshToken}` 契约不变；改密强制下线
  - 短信验证码经插件分发（`pluginService.Invoke`）
- **插件调用接口**：`POST /admin/plugin/info/invoke` 直接调用插件导出方法（演示/联调用）
- **`example/` 插件 demo**：完整可运行示例，覆盖 pluginInfo/cache/pluginService 与 `@baseDir/` 配置路径解析

### 变更（破坏性）
- **pluginsdk 并入 v 模块**：import 路径 `github.com/vera-byte/vgo/pluginsdk` → `github.com/vera-byte/vgo/v/pluginsdk`，旧独立模块不再单独发版；脚手架模板与文档同步更新

### 修复
- 日志中间件 multipart 二进制请求体入库崩溃（PNG 魔数 0x89 破坏 UTF-8）；日志参数脱敏/截断（已知问题 #31）
- 通用 CRUD Add 钩子把新建 id 传入 ModifyAfter（修复默认地址被后置钩子误清）
- `vgo-tools plugin-pack` 构建隔离 `GOWORK=off`（插件项目独立于宿主 go.work）

## v1.1.0（2026-11）—— 现代化改造

### 平台升级
- **Go 1.24 → 1.27.3**，全模块 go 声明同步
- **GoFrame v2.9.3 → v2.10.4**（容器组件泛型化、gcfg/gdb/ghttp 兼容回归通过）

### 认证体系（破坏性变更）
- **JWT 退役，全面切换 sa-token-go**（Random64 服务端会话）
  - 强制重新登录（旧 JWT 失效）；前端登录响应结构保持不变
  - 顶号挤下线、刷新令牌轮换（旧 RT 作废重签）、改密强制下线
  - 超管改为**角色 `label=admin`**（移除 `UserId==1` 硬编码）
- 密码存储 **MD5 → bcrypt**（存量哈希登录成功后自动升级）

### 安全加固（高危修复）
- 真实凭证移出仓库，全部改 `VGO_*` 环境变量注入
- **SQL 注入**：列表排序参数白名单化（原 order/sort 直接拼接）
- **越权（高危）**：`personUpdate` 可携带任意 `id` 改他人密码/角色 → 强制本人 + 字段白名单
- 上传扩展名白名单（拦截 html/svg/js 等）+ 随机文件名存储
- 对外错误统一脱敏；验证码明文移出日志
- OpenAPI：nonce 防重放（Redis 一次性）、待签串分隔符规范（兼容旧格式验签）
- 敏感接口限流（登录/刷新 20rpm，开放平台 60rpm/每 IP）

### PostgreSQL 支持修复
- 迁移文件方言修正（MySQL `COMMENT` → PG `COMMENT ON COLUMN`，110 处）
- **camelCase 列名引用修复**（原始 Where/Join 裸串折叠导致登录/列表全挂）
- migrate 命令支持 `modules/*/resource/migrates` 多模块 + 独立版本表
- 用户/日志列表 PG 适配（`string_agg`、JOIN 别名、GROUP BY）

### 功能
- **插件系统**：ZIP 插件包安装/启停/卸载；插件为**独立可执行程序**（pluginsdk + stdio JSON-RPC），Hook 插件可接管上传等内建行为；`vgo-tools plugin` 一键生成插件项目脚手架、`vgo-tools plugin-pack` 一键交叉编译多平台并打包安装 ZIP
- **数据回收**：删除自动快照入回收站（），支持查询/恢复/按保留期清理（每日 cron），参照 cool-admin-midway recycle 模块

### 工程化
- 多模块 `replace` 本地化：克隆即可构建（`GOWORK=off` 实证），发布走模块 tag
- 清理 gf v1.16.9 死依赖、initdb 死代码、`Prefix`/`package demo`/`tast_start_func.go` 等命名问题
- **测试门禁**：安全核心单测 ×5、`make test`/`make vet`、GitHub Actions CI
- 文档体系 VuePress → **Mintlify**
